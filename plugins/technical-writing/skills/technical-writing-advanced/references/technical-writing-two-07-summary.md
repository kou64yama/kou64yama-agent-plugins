# Summary of Technical Writing Two

<br />

> [!NOTE] **Estimated Time:** 1 minute

Congratulations! You've completed the pre-class portion of Technical Writing
Two, which covered the following intermediate principles of technical writing:

| Section                                                           | Lesson                                                                                                                                                        |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Self-editing](./technical-writing-two-02-editing.md)             |
| [Self-editing](./technical-writing-two-02-editing.md)             | Adopt a style guide.                                                                                                                                          |
| [Self-editing](./technical-writing-two-02-editing.md)             | Think like your audience.                                                                                                                                     |
| [Self-editing](./technical-writing-two-02-editing.md)             | Read documents out loud to yourself.                                                                                                                          |
| [Organizing large docs](./technical-writing-two-03-large-docs.md) |
| [Organizing large docs](./technical-writing-two-03-large-docs.md) | Determine whether to organize a large amount of information into a single long document or a collection of shorter documents.                                 |
| [Organizing large docs](./technical-writing-two-03-large-docs.md) | Outline first. Alternatively, write free form and then reorganize.                                                                                            |
| [Organizing large docs](./technical-writing-two-03-large-docs.md) | Introduce a large document by explaining what it covers.                                                                                                      |
| [Organizing large docs](./technical-writing-two-03-large-docs.md) | Choose headings that describe the task your reader is working on.                                                                                             |
| [Illustrating](./technical-writing-two-04-illustrations.md)       |
| [Illustrating](./technical-writing-two-04-illustrations.md)       | Consider writing the caption _before_ creating the illustration.                                                                                              |
| [Illustrating](./technical-writing-two-04-illustrations.md)       | Constrain the amount of information in a single drawing.                                                                                                      |
| [Illustrating](./technical-writing-two-04-illustrations.md)       | Focus the reader's attention on the relevant part of a picture or diagram by describing the takeaway in the caption or by adding a visual cue to the picture. |
| [Creating sample code](./technical-writing-two-05-sample-code.md) |
| [Creating sample code](./technical-writing-two-05-sample-code.md) | Create sample code that is accurate, clear, short, easy to understand, and well-commented.                                                                    |
| [Creating sample code](./technical-writing-two-05-sample-code.md) | Consider providing not only examples but also anti-examples.                                                                                                  |
| [Creating sample code](./technical-writing-two-05-sample-code.md) | In tutorials, provide code samples that demonstrate a range of complexity.                                                                                    |
| [Using LLMs in tech writing](./technical-writing-two-06-llms.md)  |
| [Using LLMs in tech writing](./technical-writing-two-06-llms.md)  | Construct detailed prompts by defining a role for the LLM, a target audience, a document type, and a specific goal.                                           |
| [Using LLMs in tech writing](./technical-writing-two-06-llms.md)  | Revise documents by prompting an LLM to reorganize content, copy edit for errors, and identify stylistic or logical issues.                                   |
| [Using LLMs in tech writing](./technical-writing-two-06-llms.md)  | Generate concise summaries by identifying the summary's purpose, target audience, and style.                                                                  |

The _in-class component_ of Technical Writing Two helps you practice
intermediate technical writing principles.

If your organization offers the instructor-led portion of Technical Writing Two,
you're now ready for that class. If your organization doesn't offer the
instructor-led portion of Technical Writing Two, note that Google occasionally
offers the course. See the
[Announcements page](https://developers.google.com/tech-writing/announcements)
for details.
