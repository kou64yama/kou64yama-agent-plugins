# Technical Writing Fundamentals

Use these principles when drafting or revising ordinary technical content.

## Workflow

1. Identify the reader, their task, prior knowledge, and what they should be
   able to do or understand afterward. Use context; ask only when a missing
   answer would materially change the writing.
2. State purpose and scope early. Organize around the reader's tasks or
   questions, with descriptive headings and prerequisites where useful.
3. Draft with familiar, precise words. Prefer concrete verbs, active voice when
   the actor matters, and concise sentences. Keep one main idea per paragraph.
4. Use numbered steps for sequences, bullets for unordered items, and tables
   only for compact comparisons or repeated properties. Label links by their
   destination or action. Format code and commands consistently.
5. Review for accuracy, missing steps, ambiguous terms, parallel structure,
   grammar, punctuation, and consistency. Preserve the author's meaning and
   technical claims; verify claims against available evidence instead of
   inventing details.

Adapt advice to the target language. English-specific grammar guidance does not
automatically apply elsewhere. Use [Technical Writing One](references/) for
sentence-level fundamentals and
[the course overview](references/technical-writing-overview.md) for source
context.
