# Summary of Technical Writing One pre-class

<br />

> [!NOTE] **Estimated Time:** 2 minutes

Congratulations! You've completed the pre-class portion of Technical Writing
One, which covered the following fundamental principles of technical writing:

| Section                                                            | Lesson                                                                                          |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [Words](./technical-writing-one-03-words.md)                       |
| [Words](./technical-writing-one-03-words.md)                       | Define new or unfamiliar terms.                                                                 |
| [Words](./technical-writing-one-03-words.md)                       | Use terms consistently.                                                                         |
| [Words](./technical-writing-one-03-words.md)                       | Avoid ambiguous pronouns.                                                                       |
| [Active voice](./technical-writing-one-04-active-voice.md)         |
| [Active voice](./technical-writing-one-04-active-voice.md)         | Prefer active voice to passive voice.                                                           |
| [Clear sentences](./technical-writing-one-05-clear-sentences.md)   |
| [Clear sentences](./technical-writing-one-05-clear-sentences.md)   | Pick specific verbs over vague ones.                                                            |
| [Clear sentences](./technical-writing-one-05-clear-sentences.md)   | Reduce _there is_ and _there are_.                                                              |
| [Short sentences](./technical-writing-one-06-short-sentences.md)   |
| [Short sentences](./technical-writing-one-06-short-sentences.md)   | Focus each sentence on a single idea.                                                           |
| [Short sentences](./technical-writing-one-06-short-sentences.md)   | Convert some long sentences to lists.                                                           |
| [Short sentences](./technical-writing-one-06-short-sentences.md)   | Eliminate unneeded words.                                                                       |
| [Lists and tables](./technical-writing-one-07-lists-and-tables.md) |
| [Lists and tables](./technical-writing-one-07-lists-and-tables.md) | Use a numbered list when ordering is important and a bulleted list when ordering is irrelevant. |
| [Lists and tables](./technical-writing-one-07-lists-and-tables.md) | Keep list items parallel.                                                                       |
| [Lists and tables](./technical-writing-one-07-lists-and-tables.md) | Start numbered list items with imperative words.                                                |
| [Paragraphs](./technical-writing-one-08-paragraphs.md)             |
| [Paragraphs](./technical-writing-one-08-paragraphs.md)             | Establish a paragraph's central point in the first sentence.                                    |
| [Paragraphs](./technical-writing-one-08-paragraphs.md)             | Focus each paragraph on a single topic.                                                         |
| [Audience](./technical-writing-one-09-audience.md)                 |
| [Audience](./technical-writing-one-09-audience.md)                 | Determine what your audience needs to learn.                                                    |
| [Audience](./technical-writing-one-09-audience.md)                 | Fit documentation to your audience.                                                             |
| [Documents](./technical-writing-one-10-documents.md)               |
| [Documents](./technical-writing-one-10-documents.md)               | Begin a document by stating its scope, audience, and key points.                                |
| [Documents](./technical-writing-one-10-documents.md)               | Aim the document at your audience.                                                              |
| [Punctuation](./technical-writing-one-10-documents.md)             |
| [Punctuation](./technical-writing-one-10-documents.md)             | Use commas to force short pauses within a sentence or to separate items in a list.              |
| [Punctuation](./technical-writing-one-10-documents.md)             | Use a period to separate distinct thoughts; use a semicolon to unite highly related thoughts.   |
| [Punctuation](./technical-writing-one-10-documents.md)             | Use a colon instead of a period in a sentence that introduces a list.                           |

If your organization offers the instructor-led portion of Technical Writing One,
you're now ready for that class. If your organization doesn't offer the
instructor-led portion of Technical Writing One, note that Google occasionally

[Announcements page](https://developers.google.com/tech-writing/announcements)
